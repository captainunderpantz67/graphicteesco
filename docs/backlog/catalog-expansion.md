## Rules for this wave (protect against Google's scaled-content policy)
1. Every product is its own design with its own joke that passes the 5-part gate (docs/research/how-to-research-a-design.md). Never the same art re-titled for another keyword; twins only on a different blank and with their own copy.
2. Run the TikTok lingo + TikTok Shop check for each niche before writing its briefs (R3.1, Sam's research standard). Write the lingo into the brief.
3. A collection page goes live (and into the sitemap) only at 3+ live products (MIN_INDEX). Before that the products sit in the broader hub (graphic-hoodies-for-men/women, graphic-sweatshirts).
4. Each collection page gets unique intro copy and 4-6 FAQs from real questions (R9), never a template with the niche swapped in.
5. Words set in real fonts (scripts/compose-print.py); fal draws the picture only. Big on the chest.
6. Order: parks, golf, capybara, dog/dachshund/pitbull, cat, bear, running, nana/grandpa, welder, pickleball, then the rest. Spread across lanes A, B, C, E.
