- "Original art, drawn for Graphic Tees Co" -> "Original art, designed for Graphic Tees Co"
- "hand-drawn" / "hand drawn" -> "hand-drawn-style"
- "we drew" -> "we designed"; "original illustration" -> "original design"; "drawn for this shirt" -> "designed for this shirt"
